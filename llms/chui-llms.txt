# Chui / Trueface

> Chui (now operating as Trueface, part of BigBear.ai) is a facial recognition and computer vision company. It provides on-device and on-premises face recognition, spoof/liveness detection, object detection, and identity verification via a licensed SDK (C++, Python, Android, iOS bindings) and a Dockerized REST API (Trueface On-Prem / PTOP). Originally launched as "Chui," the world's first faceprint API, the technology is distributed today under the Trueface brand.

Notes:
- No public OpenAPI/Swagger specification is published; the REST surface (Trueface On-Prem) ships as a self-hosted Docker container.
